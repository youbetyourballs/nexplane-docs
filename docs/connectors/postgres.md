# PostgreSQL Connector

!!! note "Coming soon"
    The PostgreSQL connector (direct connection mode) is planned but not yet available. This page will be updated when the connector is released.

## Planned Capabilities

The PostgreSQL connector will support direct database connections for user provisioning, permission management, and audit log configuration — without requiring the Nexplane Agent. For PostgreSQL running on managed hosts, the [Nexplane Agent](nexplane-agent.md) `dbadmin` package already supports PostgreSQL user management today.
