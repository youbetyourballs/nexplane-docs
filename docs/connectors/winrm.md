# WinRM Connector

!!! note "Coming soon"
    The WinRM connector is planned but not yet available. This page will be updated when the connector is released.

## Planned Capabilities

The WinRM connector will support executing typed command templates on Windows hosts via Windows Remote Management — without requiring the Nexplane Agent. Planned capabilities include service management, local user management, and PowerShell-based hardening operations. For Windows hosts you manage, consider using the [Nexplane Agent](nexplane-agent.md) instead, which provides a richer command set and outbound-only connectivity.
